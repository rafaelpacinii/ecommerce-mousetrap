# Homepage static artwork

The active fallbacks are `g-pro-superlight-speed.webp`,
`g-pro-superlight-precision.webp`, `g-pro-superlight-light.webp` and
`g-pro-superlight-glide.webp`. Each is a 1024×1024 alpha WebP cropped/padded from a
real Blender frame of the same fixed Superlight model as the active scroll sequence.
They carry the same asset-version query as the animated frames.

Source: **Computer mouse**, **zhe_kan**, **CC BY 4.0**. The public home disclosure
credits the source/license and adapted materials, lighting and animation. See
[the source and studio delivery](../../../../docs/others/homepage-product-render/README.md).
